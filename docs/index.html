Robo Historias

Robo Historias é uma ferramenta de automação de uso próprio que cria histórias animadas curtas com inteligência artificial e as publica no canal do YouTube Alice Oliveira.

A ferramenta acessa somente o canal do seu próprio dono, por meio da API de Dados do YouTube, e não é oferecida a outros usuários.
